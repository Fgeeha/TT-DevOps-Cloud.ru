# 02-ansible

## обоснование

Используется алгоритм least_conn (наименьшее количество подключений),
так как он равномерно распределяет нагрузку на экземпляры приложения,
учитывая текущее количество активных соединений. Это эффективно в ситуации,
когда разные запросы могут обрабатываться с разной скоростью.
